# Project-Scoped Rules for Golden Stallion / Silks.AI HKJC Predictor

## 🚨 Synchronization Constraints
- **Zero Local-Only State**: This application is used live by clients at the racetrack via [https://silks-ai.onrender.com/](https://silks-ai.onrender.com/). We must never leave updated predictions or scraped results only in the local directory.
- **Immediate Push Protocol**: Any script execution that modifies prediction files or scrapes new results (including `run_predictions.py`, `get_detailed_picks.py`, or track condition monitor runs) must be followed immediately by a git stage, commit, and push of the updated files in `data/` to `origin main` to trigger automatic deploy to Render (https://silks-ai.onrender.com/).
- **Merge Conflict Strategy**: Always resolve conflicts in data files by preferring the local/freshest state generated by the model runs using `git pull origin main -X ours`.
